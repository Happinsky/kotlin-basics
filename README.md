# Kotlin Learning Archive



Zbiór skryptów i ćwiczeń zrealizowanych podczas nauki języka Kotlin. Repozytorium dokumentuje proces poznawania składni oraz programowania obiektowego .



### 📂 Co zawierają te skrypty?

* **Podstawy programowania:** Zmienne, pętle `for`, instrukcje warunkowe `if/when` oraz listy i mapy.

* **Programowanie obiektowe (OOP):** Tworzenie klas, dziedziczenie (klasy `Zwierzak` i `Pies`), interfejsy (`Latajacy`, `Zdolnosc`) oraz `data class`.

* **Mechanizmy języka:** Obsługa `Null Safety`, `init` bloki, klasy typu `enum` oraz funkcje lambda (np. `filter` i `map`).

* **Logika biznesowa:** Proste systemy (np. `KontoBankowe`, system profesji bohatera w grze).
